# 移动端专属链接生成器

这是一个简单的Web应用程序，用于生成仅允许在移动设备上访问的链接。当用户尝试在桌面设备上打开这些链接时，系统会显示错误消息，并提供一个二维码供移动设备扫描访问。

## 功能特点

- 将任何网址转换为仅限移动设备访问的链接
- 易于分享和使用的短链接格式
- 为非移动设备用户提供友好的错误页面和二维码
- 访问统计记录
- 响应式设计，兼容各种设备

## 安装说明

1. 将所有文件上传到您的Web服务器，保持文件夹结构不变
2. 确保您有权访问的MySQL数据库
3. 修改`config.php`中的数据库连接信息
4. 访问`install.php`创建必要的数据库表，或者系统会在首次使用时自动创建
5. 确保PHP版本 >= 7.0
6. 确保服务器支持mod_rewrite模块（如果使用Apache）

## 使用指南

### 基本使用

1. **生成单个链接**
   - 访问网站首页
   - 在输入框中粘贴您要分享的URL
   - 设置访问密码（用于后续删除链接）
   - 选择访问限制类型（仅限移动设备/任意设备可访问）
   - 点击"生成专属链接"按钮
   - 复制生成的链接并分享

2. **批量转换链接**
   - 切换到"批量转换"选项卡
   - 每行输入一个URL
   - 设置统一的访问密码
   - 选择访问限制类型
   - 点击"批量生成专属链接"
   - 可以单独复制或一键复制所有生成的链接

3. **查看历史记录**
   - 点击页面顶部的"查看历史记录"
   - 可以查看之前生成的所有链接
   - 支持按日期、访问次数等排序
   - 可以删除不需要的链接（需要输入创建时设置的密码）

### 特殊功能

1. **网盘链接优化**
   - 系统自动识别常见网盘分享链接
   - 为不同网盘提供定制的访问提示
   - 显示对应网盘图标，提升用户体验

2. **访问统计**
   - 记录每个链接的访问次数
   - 显示最后访问时间
   - 提供简单的访问趋势分析

### 注意事项

1. **链接安全**
   - 请妥善保管访问密码，这是删除链接的唯一凭证
   - 不建议分享敏感或重要的私密内容
   - 定期检查并清理不再使用的链接

2. **访问限制**
   - "仅限移动设备"的链接在桌面设备上会显示提示页面
   - 提示页面包含二维码，方便手机扫码访问
   - "任意设备可访问"的链接没有设备限制

3. **兼容性**
   - 支持主流移动设备和浏览器
   - 自适应不同屏幕尺寸
   - 优化触屏操作体验
